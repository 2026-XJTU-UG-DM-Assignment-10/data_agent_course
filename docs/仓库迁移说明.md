在各自项目根目录执行：

```powershell
git remote set-url origin https://github.com/2026-XJTU-UG-DM-Assignment-10/data_agent_course.git
git fetch origin
git remote -v
```

原有代码和个人分支可以继续使用，不需要删除文件或重新下载项目。需要合入主分支文档更新时，先提交个人修改，再在个人分支执行 `git merge origin/main`。
