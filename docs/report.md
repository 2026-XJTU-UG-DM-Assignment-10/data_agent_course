## 模型决策、工具执行与处理案例

| 阶段 | 实际方法与边界 |
| --- | --- |
| 检测 | A调用B的共享规范化视图，输入不变，统计原始缺失和解析后问题 |
| 模型计划 | 只读训练摘要；读取缺失率、偏度、四分位数和IQR并说明理由 |
| 本地校验 | 五个白名单决策字段；固定步骤本地设置；无效计划最多修正一次 |
| 清洗与测试 | B先去重/非法置空/训练拟合填补/最终去重；测试只应用训练状态 |
| 分类与导出 | D训练逻辑回归；C统一日志、审计、CSV、图像和运行结果 |

真实模型选择median：capital_gain偏度11.4218、均值1142.0185而中位数0；capital_loss偏度4.4913；fnlwgt偏度1.3849。即使部分字段较对称，当前契约仍要求所有数值列共用一种策略。

真实模型选择Unknown：workclass缺失率约9.89%、occupation约9.47%、native_country约6.99%，保留缺失为独立类别。规则模式的median/Unknown是固定设置，与模型理由来源分开记录。

| 训练分布自适应 | 提供合法数值偏度/四分位数/IQR与逐列缺失率，要求模型引用统计解释策略 |

页面只在点击“开始处理”后调用唯一生产pipeline；预检、重绘和回放不新增模型请求。上传文件按内容哈希保存；应用预检每份限制20 MB。训练不足5000行可用于功能自测，页面明确提示不符合正式规模。
