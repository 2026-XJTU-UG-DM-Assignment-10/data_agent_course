# 项目文档入口

当前已将四人协作资料放入仓库，并把公共代码和样本放入 `src/`、`examples/`。无需再复制 starter 目录，也不要在本项目内再创建同名项目。

| 文档 | 用途 |
| --- | --- |
| [统一入口](START_HERE.md) | 所有成员与任何 AI 的必读顺序、能力边界和恢复流程 |
| [低沟通协作协议 2.0](低沟通协作协议.md) | 固定接口、独立开发、自动交接和 D 异步集成 |
| [项目任务书](数据处理智能体_AI开发任务书.md) | 两周及格版目标、范围、交付物和排期 |
| [四人分工与协作](四人分工与协作.md) | 文件归属、交接、集成与展示分工 |
| [公共接口说明](公共接口说明.md) | v1.0 函数、数据结构、计数口径和异常规则 |
| [成员 A 任务](成员A_AI任务.md) | 数据与检测 |
| [成员 B 任务](成员B_AI任务.md) | 规范化与清洗 |
| [成员 C 任务](成员C_AI任务.md) | 模型、计划、总流程和日志 |
| [成员 D 任务](成员D_AI任务.md) | 分类、页面、公共文件与集成 |
| [公共文件检查记录](公共文件检查记录.md) | 已验证的共享部分及当前边界 |
| [接口变更记录](interface_changes.md) | 公共契约变更统一入口 |
| [仓库迁移说明](仓库迁移说明.md) | 组织归属、远程新地址、旧副本更新与迁移核对记录 |
| [线上讨论会提要](线上讨论会提要.md) | 可直接展示的议程、分工、验收标准与人员/勾选/数字式决议记录 |
| [集成检查记录](integration_log.md) | D 的接受、退回及课程最终验收清单 |

给不能直接读取仓库的 AI：运行 `python scripts/build_ai_briefs.py`，使用 `outputs/ai_briefs/member_X_AI_brief.md`。可提交的验证摘要规范见 `../evidence/README.md`，角色自测规范见 `../checks/README.md`。

每位成员维护已建立的 `handoff_A.md` 至 `handoff_D.md` 和 `../handoffs/X.json`。独立开工词在 `../prompts/X.md`，机器清单在 `../collaboration/roles.json`。未实际运行的内容保留 not_run，不写已通过。
